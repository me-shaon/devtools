# DevTools v2.1.1

## Highlights

- DevTools now updates itself. It checks for updates when it starts and every 6 hours while it runs, downloads a new version in the background, and installs it when you quit DevTools.
- When an update is ready, a notice offers "Restart now" if you want it right away.

## App Updates

- Turn off "Update automatically" in the sidebar to update by hand instead. You choose when to download and when to restart.
- The command palette search field no longer has a blue box around it.
