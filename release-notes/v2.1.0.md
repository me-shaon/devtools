# DevTools v2.1.0

## Highlights

- Open any tool from Raycast, Alfred, Shortcuts, a terminal, or a browser with a `devtoolsapp://` link. For example, `devtoolsapp://open/json-viewer` opens JSON Viewer.
- A link opens the tool in the DevTools window that is already running. It does not start a second copy.

## New AI Tools

- Image Metadata Cleaner removes AI prompts, Content Credentials (C2PA), AI-generated labels, GPS location, and camera data from JPEG, PNG, and WebP images. It can keep the original pixels, or save a clean copy as JPG, PNG, WebP, or AVIF. It does not remove watermarks that are hidden in the pixels.
- Secret & PII Redactor masks API keys, tokens, passwords, emails, and other personal data before you paste text into an AI chat. It can put the original values back into the reply.
- Token Counter counts GPT tokens exactly and estimates tokens for Claude, Gemini, and Llama. It also shows how much of a context window the text uses, and estimates cost from prices that you enter.
- AI Text Cleaner removes hidden characters and citation markers from AI-written text. It also straightens quotes and can remove Markdown.

## Search

- Tools now have search keywords. For example, "sha" finds Hash Generator, and "yml" finds YAML to JSON.
- Launchers such as the DevTools Raycast extension read the tool list from the app, so they show new tools without an update.

## Links

- `devtoolsapp://open/<tool-id>` opens a tool.
- `devtoolsapp://search?q=<text>` opens the command palette with the text.
- `devtoolsapp://home` shows the home page.
