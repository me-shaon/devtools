# DevTools v2.2.0

## Highlights

- Most tools now update as you type. You no longer press a Convert, Test, or Validate button.
- JSON Viewer reads Python dicts, Ruby hashes, JavaScript objects, JSON5, and NDJSON. It converts them to valid JSON and lists each repair it made.
- JWT Decoder verifies RS, PS, ES, and EdDSA tokens with a PEM key, a JWK, or a JWKS. It can also sign test tokens.
- Cron Calculator explains any cron expression in plain English and shows the next runs in your time zone.

## New Tools

- PHP Tools converts serialize() data, PHP session data, and PHP arrays to JSON and back. It repairs string lengths that a database search-and-replace broke.
- Date Format Translator converts date format strings between Go, strftime (C, Python, Ruby), Java, date-fns, Moment.js, PHP, and .NET. It warns when a target has no exact match.
- YAML to JSON is now Config Converter. It converts between JSON, YAML, TOML, .env, and Java .properties files in any direction.

## Tool Improvements

- Regex Tester (formerly Regex Generator) highlights matches in the text and shows capture groups. It also replaces with `$1`. A pattern that runs too long stops after 2 seconds, so the app does not freeze.
- Timestamp reads seconds, milliseconds, microseconds, and nanoseconds automatically. It accepts date strings and offsets such as `now - 1d`, and shows extra time zones.
- Cron Calculator reads standard, Quartz, and AWS expressions, macros such as `@daily`, and full crontab lines. Error messages name the field and the allowed range.
- QR Generator has templates for Wi-Fi, contacts, email, phone, SMS, locations, and events. You can choose the error correction level and add a logo. You can save the code as SVG.
- Color Palette reads any CSS color, including alpha, HWB, OKLCH, and named colors. It has a color picker.
- Number Base shows binary, octal, decimal, hex, and a custom base at the same time, with signed 8 to 64-bit views.
- Case Converter shows every case at the same time and splits acronyms correctly, so `HTTPServerID` becomes `http_server_id`. It adds Train-Case and dot.case.
- Lorem Ipsum generates names, emails, URLs, and titles, as text or as a JSON array.
- CSV to JSON flattens nested objects into dot keys such as `user.address.city`. It can save the file, with a BOM for Excel.
- Text Compare aligns changed lines, so one inserted line no longer marks all later lines as changed. It adds a word view, a Swap button, and previous and next change buttons.
- JSON Viewer keeps large numbers exact and shows the position of an error in the input.

## App Updates

- Paste detection now also suggests PHP Tools, Config Converter (TOML and .env), and the new cron, color, and number forms.
- Pasting a timestamp into the app now fills the Timestamp input.
