# DevTools v2.0.0

## Highlights

- DevToolsApp is now DevTools, with a new logo and a redesigned workspace.
- DevTools now runs on Tauri instead of Electron. All tools work the same way as before.
- The download is much smaller. The macOS, Windows, and Linux installers are now about 3 MB. They were about 100 MB before.
- The app uses about 40% less memory. On macOS, it uses about 80 MB at idle. Before, it used about 140 MB.
- Updates are smaller and faster. An update download is now about 3 MB.

## Upgrading from v1.3.0

- Click the update button in the app to move to this version.
- On macOS, the app closes after the update. Open DevTools again to start the new version.
- On Windows, the new installer removes the old version.
- On Linux, the new `.deb` and `.rpm` packages replace the old `devtools` package.
- Your favorites, recent tools, theme, and custom shortcuts do not move to the new version. Set them again after the update.

## App Updates

- Files that you download, such as QR codes and compressed images, now open a save dialog so that you can select the folder.
- Links now open in your default browser.
- On macOS, closing the window keeps the app in the Dock. Click the Dock icon to open the window again.
