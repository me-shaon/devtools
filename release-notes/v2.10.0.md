# DevTools v2.10.0

## Highlights

- Mermaid Renderer can now draw flowcharts on a canvas. Add nodes, pick shapes, and drag links between nodes. The Mermaid text updates as you draw.
- The Markdown editor has a formatting toolbar with keyboard shortcuts.
- Undo and redo in code editors now also revert Clear, Paste, and Format.

## Tool Improvements

- Mermaid Renderer has a new Draw mode for flowcharts. Drag from a dot on a node to link it to another node, or drop the link on the empty canvas to add a linked node. Click a node or a link to change its label, shape, line, or arrow head. Text that you type updates the canvas.
- The Markdown editor toolbar has bold, italic, headings, strikethrough, lists, task lists, quotes, code, tables, links, and images. Enter continues a list or a quote, and Tab indents list items.
- The Markdown and HTML editors scroll together with their previews, and the preview keeps its position when it reloads.
- Undo follows your OS keys: Cmd+Z and Shift+Cmd+Z on macOS, and Ctrl+Z and Ctrl+Y on Windows and Linux.
- DB Diagram shows the full column handles, and reference lines meet the table edge.
- QR Generator keeps the QR code visible after you change the pane layout.
