# DevTools v2.9.0

## Highlights

- Markdown now supports GitHub Flavored Markdown and HTML: tables, task lists, and HTML such as `<details>` and centered images.
- Email Reader shows Outlook messages that keep their formatting only in Rich Text (RTF).
- Email Reader stays responsive while it reads a large file.

## Tool Improvements

- Markdown renders HTML blocks and inline HTML, tables, task lists, strikethrough, and links in plain text. Code blocks show HTML as code. Scripts, forms, frames, and style tags are removed.
- The Markdown preview blocks images from the web. Select Load images to show them for the document. Links in the preview open in your browser.
- The Markdown and Email Reader previews follow the app's light or dark theme.
- Email Reader shows the original HTML or text of an Outlook .msg file when Outlook stored it only as compressed RTF.
- DB Diagram and Mermaid Renderer now use the full width and height of the window, like the other editor tools.
