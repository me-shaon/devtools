# DevTools v2.7.0

## Highlights

- Two new tools: Mermaid Renderer and Time Zone Converter.
- Code Playground now runs JavaScript in a sandbox. Your code cannot reach the app or the network, and an endless loop no longer freezes the app.
- The gradient builder is interactive. Drag stops on the preview bar, and move them with the keyboard.
- Color Palette lets you edit the RGB and HSL channels and alpha directly.

## New Tools

- Mermaid Renderer shows a Mermaid diagram as you type. Start from a flowchart, sequence, class, ER, state, Gantt, mind map, pie, or Git graph template. Copy the SVG, or save it as SVG or PNG.
- Time Zone Converter converts a date and time from one time zone to UTC, local time, and the zones you add. It handles daylight saving time changes and shows when the date changes.

## Tool Improvements

- Code Playground stops a run after 5 seconds or when you start a new run. Logs from async code now show in the console, and top-level await works.
- Click the gradient preview bar to add a stop, up to 16 stops. The handles at 0% and 100% are no longer cut in half.
- Press Enter in the color field to apply the color.
- The color compare list checks up to 32 colors and tells you which entries it ignored.
- The color blindness sample text now previews your working color. The severity slider goes down to 0%.
- The color blindness image simulation limits the image size. If it rejects an image, it keeps the current image.
