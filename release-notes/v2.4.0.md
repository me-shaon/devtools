# DevTools v2.4.0

## Highlights

- JSON Diff compares two JSON or YAML documents by value. It ignores key order, lists each change by its path, and can match array items by a key such as `id`. Copy the changes as text or as a JSON Patch.
- HAR Viewer opens a .har file from the browser Network panel. Filter and sort the requests, see headers, bodies, and timings, and copy a request as cURL. Save a sanitized copy without credentials and cookies before you share the file.
- IP / CIDR Calculator shows the network, broadcast, host range, masks, and address type for IPv4 and IPv6 blocks. It also splits, merges, and checks ranges.
- chmod Calculator sets file permissions with checkboxes, octal, or `rwx` text. It applies expressions such as `u+x` and shows the chmod commands, a plain-English summary, and umask defaults.

## Tool Improvements

- Config Converter reads and writes TOON (Token-Oriented Object Notation). When one side is TOON, it shows how many LLM tokens TOON saves against JSON.
- Number Base calculates integer expressions such as `(1 << 12) - 1`. It also has a bit grid that you can click, and it shows Roman numerals.
- Case Converter makes URL slugs and removes accents.
- Escape Tools converts domain names to and from Punycode, for example `münchen.de` and `xn--mnchen-3ya.de`.
- String Inspector shows the NFC, NFD, NFKC, and NFKD forms. It warns when one character is written in two different ways.

## App Updates

- A new Network category holds IP / CIDR Calculator and HAR Viewer.
- Paste detection now also suggests HAR Viewer, IP / CIDR Calculator, chmod Calculator, and Config Converter for TOON.
