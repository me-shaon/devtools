# DevTools v2.8.0

## Highlights

- Two new tools: DB Diagram and Email Reader.
- DB Diagram draws a database schema from DBML text. Edit tables, columns, and references on the canvas, and the text updates.
- Email Reader opens .eml and Outlook .msg files on your computer. The HTML preview never loads remote images.

## New Tools

- DB Diagram draws an ER diagram as you type DBML. Drag tables, and draw a reference from one column to another. Click a table or a column to rename it, change its type and flags, or delete it. Your comments in the DBML stay.
- DB Diagram imports SQL from PostgreSQL, MySQL, SQL Server, Snowflake, and SQLite, and it imports a Mermaid erDiagram. It exports SQL for PostgreSQL, MySQL, SQL Server, and Oracle, a Mermaid erDiagram, JSON, SVG, or PNG. Open and save .dbml files. The DBML syntax reference is in the app, so it works offline.
- Email Reader shows the sender, recipients, date, headers, plain text, and HTML of a message. Paste the source of an email, or drop a .eml or .msg file. Images attached to the message show in the preview, and you can save each attachment.

## Tool Improvements

- Image Metadata Cleaner names the app that made an image with newer Content Credentials, such as ChatGPT images. It showed "info" before.
