# DevTools v2.6.0

## Highlights

- Image Converter now writes real WebP files on macOS. Before this release, "Convert to WebP" saved a PNG with a .webp name.
- Image Converter can now output AVIF. JPEG output uses MozJPEG and PNG output uses OxiPNG, so files are smaller at the same quality.
- Image Converter can resize images (Lanczos3, Mitchell, Catmull-Rom, or Triangle) and reduce the color palette to 2 to 256 colors, in single and bulk mode.
- Four new tools: XML Inspector, ASN.1 Inspector, Checksum, and Stopwatch.

## New Tools

- XML Inspector formats or minifies XML, and queries nodes or values with XPath 1.0 and namespace prefixes.
- ASN.1 Inspector shows DER or BER data from PEM, Base64, hex, or a file as a tree of tags, offsets, lengths, and values.
- Checksum calculates six common CRC variants from text, hex bytes, or a file, and validates or appends Luhn check digits.
- Stopwatch records laps and split times, and copies or exports them as CSV. It keeps running while you use other tools.

## Tool Improvements

- Color Palette uses one working color for the converter, the palette, and the contrast checker. Select a swatch to use it.
- Color Palette adds complementary, analogous, triadic, split complementary, and monochromatic palettes. Copy any palette as CSS variables or JSON.
- The contrast checker suggests the closest passing color for a WCAG target, and applies it in one click.
- Color Palette keeps your last 8 colors, adds a gradient builder, and no longer shows duplicate swatches for very light or dark colors.
- The color blindness severity slider now also applies to achromatopsia.
- Image Converter has an Edit Image tab to crop, resize, rotate, and flip an image.
- HTML Preview adds device sizes, zoom, a width handle, and full screen.
- Cron Calculator has a visual builder that builds a schedule one field at a time.
- Line Tools has a Transform mode to split, join, wrap, replace, sum, or multiply lines.
- The image and video metadata cleaners open the file picker when you click the empty drop area.

## App Updates

- Right-click a workspace tab to close it, the other tabs, the tabs to the right, or all tabs.
- Dropdowns now match the text fields, and fields show focus with a soft halo.
- Fixed hidden labels that made the whole page scroll in the Below layout of some tools.
