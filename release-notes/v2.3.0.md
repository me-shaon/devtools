# DevTools v2.3.0

## Highlights

- Key Pair Generator makes Ed25519, ECDSA, and RSA keys as PEM, JWK, and OpenSSH files, with SHA-256 fingerprints. Paste a key to see its type, size, and fingerprints.
- JSON Schema Validator checks JSON or YAML against a schema as you type. Each error shows its path, and a click selects the value in the data.
- Compression decodes GZIP, zlib, and raw deflate data from Base64, hex, or a file. It also reads Helm release data, which is Base64-encoded twice.
- Semver Calculator checks version ranges for npm, Cargo, Composer, and Python, and compares two versions.

## Tool Improvements

- Line Tools compares two lists and shows the items only in A, only in B, in both, and in either. It can also keep or remove lines that match text or a regex.
- Base64 encodes and decodes Base32, for example TOTP secrets. Binary results now show as hex.
- Color Palette simulates color blindness for the current color, the contrast pair, a list of colors, and images. It warns when two colors become hard to tell apart.

## App Updates

- Paste detection now also suggests Compression, JSON Schema Validator, and Key Pair Generator.
- Ajv loads only when you open JSON Schema Validator, so the app starts as fast as before.
